# L-moments-como

Utilities for working with **L-moments** — summary statistics derived from
linear combinations of order statistics. L-moments (and the related L-moment
ratios such as L-scale, L-skewness, and L-kurtosis) are more robust to
outliers and exist under weaker conditions than conventional (product)
moments, which makes them well suited to fitting and comparing probability
distributions from sample data.
